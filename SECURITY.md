# Security Policy

## Supported Versions

The SnapSurf project provides security updates only for the latest maintained version.

| Version | Supported |
|---------|-----------|
| Latest  | Yes       |
| Older   | No        |

---

## Reporting a Vulnerability

If you believe you have found a security vulnerability in SnapSurf, please report it responsibly.

- Do not disclose the issue publicly.
- Do not open a public GitHub issue for sensitive vulnerabilities.

Please report all security issues via email:

<a href="mailto:danggiaminhmicrosoft@gmail.com">
  <img src="https://www.svgrepo.com/show/14478/email.svg" width="14" /> danggiaminhmicrosoft@gmail.com
</a>

Include the following details in your report:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes (if available)

---

## Response Policy

All reports will be reviewed promptly.

You can expect:
- Acknowledgement of receipt within a reasonable timeframe
- Assessment of severity and impact
- Ongoing communication if clarification is needed

Security issues are prioritized and handled with care.

---

## Disclosure Policy

We follow responsible disclosure practices:

- Vulnerabilities should not be publicly disclosed until a fix is available
- Once resolved, relevant details may be shared transparently

---

## Scope

This policy applies to:
- Core SnapSurf compiler
- Runtime components
- Official tooling and repositories

---

## Notes

Security is taken seriously. Responsible reporting helps maintain the integrity and reliability of the SnapSurf ecosystem.
